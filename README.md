# Aircraft Info Search

A Python program to scrape and search ICAO aircraft type designator data.

This project includes:

1. `utils/aircraft_designator_extractor.py` – Scrapes aircraft data from the official ICAO database and saves it as CSV and JSON.  
2. `main.py` – Provides a simple CLI interface to search the local SQLite aircraft database.

---

## Features

- Scrape the ICAO aircraft database from [ICAO DOC 8643](https://www2023.icao.int/publications/DOC8643/Pages/Search.aspx).  
- Store the aircraft data in a SQLite database (`icao_aircraft.db`).  
- Search aircraft by manufacturer, model, description, or type designator.  
- Display results in a formatted table or get the type designator only.  

---

## Requirements

- Python 3.9+
- Selenium
- Chrome or Chromium
- ChromeDriver

Install dependencies using pip inside a virtual environment:

```bash
python -m pip install --upgrade pip
python -m pip install selenium
```

---

## Usage

### 1. Scraping ICAO Aircraft Data

```bash
python utils/aircraft_designator_extractor.py
```

- Scrapes all pages from the ICAO website.  
- Saves the data as `icao_aircraft_data.csv` and `icao_aircraft_data.json`.  
- Can run headless (no browser window) or with a visible browser for debugging (adjust `headless=True/False` in the `main`    funcition in `aircraft_designator_extractor.py`).  

### 2. Searching the Local Database

```bash
python main.py
```

- Interactive CLI menu:

```
1. Search for aircraft
2. Get type designator only
3. Quit
```

- Enter the model/manufacturer to search, or get the type designator for a specific aircraft.

---

## Notes

- The scraper waits for tables to load and attempts to show 100 entries per page for faster scraping.  
- `main.py` requires that `icao_aircraft.db` exists; run the scraper first to populate the database.
  - There is an included database that is up to date at the time of commit.
- The program handles basic exceptions and provides informative messages if errors occur during scraping or searching.
